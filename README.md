# CLIPME — сайт

Одностраничный сайт CLIPME: оплата за проверенные просмотры коротких видео, задания, маркетплейс, страницы для брендов, тарифы и FAQ.

Открыть: `index.html` в браузере или через GitHub Pages.

Регистрация, личный кабинет и модерация работают только в версии на claude.ai — там у страницы есть база данных. На GitHub Pages сайт открывается в режиме просмотра: анкету видно, но отправить её нельзя.
